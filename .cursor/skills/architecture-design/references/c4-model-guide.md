# Guia do Modelo C4

## Níveis do Modelo C4

### 1. Context Diagram
- Visão de alto nível
- Sistema e usuários/sistemas externos
- Mostra o "big picture"

### 2. Container Diagram
- Componentes principais do sistema
- Aplicações, bancos de dados, filas
- Mostra a estrutura técnica

### 3. Component Diagram
- Estrutura interna de um container
- Classes, módulos, serviços
- Detalhamento técnico

### 4. Code Diagram
- Implementação real
- Classes e métodos
- Geralmente gerado automaticamente

## Notação

- **Pessoa** - Retângulo com ícone de pessoa
- **Sistema** - Retângulo com borda
- **Container** - Retângulo com etiqueta
- **Componente** - Retângulo menor dentro de container
- **Relação** - Seta indicando interação
