# Padrões de Documentação

## Diretrizes Fundamentais

- Sempre que criar uma função, classe ou componente, documente-o utilizando DocString, explicando sucintamente o que ela faz, seus argumentos e o retorno da função.
- E documente também no arquivo pertinente (Como API, DataBase, Frontend, Backend, etc...) em seus respectivos diretórios.

## Aplicação

Estes padrões devem ser seguidos em toda documentação de código gerada pelo codebase-documenter.
