# QA Testing

Skill para planejamento e execução completa de testes.

## Quando Usar

- Criação de estratégia de testes
- Geração de casos de teste
- Execução de testes
- Validação de qualidade
- Geração de relatórios de teste

## Instruções

1. **Estratégia de Testes**
   - Defina níveis de teste (unitário, integração, sistema, E2E)
   - Identifique ferramentas de teste
   - Defina critérios de aceitação
   - Estabeleça cobertura mínima

2. **Casos de Teste**
   - Gere casos baseados em requisitos funcionais
   - Crie casos para requisitos não-funcionais
   - Inclua casos positivos e negativos
   - Documente pré-condições e pós-condições

3. **Testes Automatizados**
   - Crie testes unitários
   - Crie testes de integração
   - Configure testes E2E (quando aplicável)
   - Configure CI/CD para execução automática

4. **Execução de Testes**
   - Execute testes manuais
   - Execute testes automatizados
   - Documente resultados
   - Identifique falhas

5. **Relatório de Bugs**
   - Documente cada bug encontrado
   - Inclua steps to reproduce
   - Classifique por severidade
   - Priorize correções

6. **Cobertura de Testes**
   - Analise cobertura de código
   - Identifique áreas não cobertas
   - Documente métricas de cobertura

## Outputs

Salve os seguintes arquivos em `outputs/artifacts/testing/`:
- `test-strategy.md` - Estratégia de testes
- `test-cases.md` - Casos de teste
- `test-scripts/` - Scripts de teste
- `test-results.md` - Resultados
- `bug-reports.md` - Relatório de bugs
- `test-coverage.md` - Cobertura
