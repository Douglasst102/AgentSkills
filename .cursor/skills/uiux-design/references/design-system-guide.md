# Guia de Design System

## Estrutura de Design System

### Cores
- **Primária** - Cor principal da marca
- **Secundária** - Cor de apoio
- **Neutras** - Cinzas para texto e fundos
- **Semânticas** - Sucesso, erro, aviso, informação

### Tipografia
- **Fontes** - Família de fontes escolhida
- **Tamanhos** - Escala tipográfica
- **Pesos** - Regular, Medium, Bold, etc.
- **Line Height** - Espaçamento entre linhas

### Espaçamento
- **Grid** - Sistema de grid (8px, 12px, etc.)
- **Padding** - Espaçamento interno
- **Margin** - Espaçamento externo

### Componentes
- Botões
- Inputs
- Cards
- Modais
- Navegação
- etc.
